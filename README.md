## 2. Deskripsi Proyek

Proyek ini bertujuan untuk menganalisis dan memvisualisasikan data transaksi penjualan supermarket menggunakan Python. Hasil analisis disajikan dalam bentuk dashboard interaktif berbasis Streamlit.

Dashboard ini membantu pengguna memahami performa penjualan berdasarkan beberapa aspek, seperti total pendapatan, jumlah transaksi, jumlah produk terjual, penilaian pelanggan, kategori produk, lokasi cabang, dan metode pembayaran.

Proyek ini menggunakan pendekatan Exploratory Data Analysis (EDA) untuk mengidentifikasi pola penjualan dan menghasilkan informasi yang dapat mendukung evaluasi bisnis.

## 3. Sumber Dataset

Dataset yang digunakan adalah **Supermarket Sales Dataset** yang dibuat oleh Aung Pyae.

- Platform: Kaggle
- Sumber dataset: https://www.kaggle.com/datasets/aungpyaeap/supermarket-sales
- Jumlah data: 1.000 transaksi
- Jumlah atribut awal: 17 kolom
- Periode transaksi: Januari sampai Maret 2019
- Objek penelitian: Transaksi penjualan supermarket

Dataset mencakup informasi transaksi, kategori produk, harga, jumlah pembelian, kota, metode pembayaran, dan rating pelanggan.
